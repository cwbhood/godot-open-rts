Ironbound @VERSION@ (build @COMMIT@)
=====================================

An open source real-time strategy game: your city builds itself, you run the
economy, trade and the army. Made with Godot 4.7.

This build is NOT code-signed. Your system will warn you the first time you
start it. That is expected for a free hobby project without a paid signing
certificate. Check the download against SHA256SUMS.txt on the release page if
you want to be sure it is the file we published.

Windows
  Unzip the folder, then double-click Ironbound.exe.
  If "Windows protected your PC" appears, click "More info", then "Run anyway".

Linux
  Unzip, then run ./Ironbound.x86_64 (chmod +x Ironbound.x86_64 if needed).
  Needs a GPU with Vulkan support.

macOS
  Unzip and move the app (named "Ironbound.app") to Applications.
  The first time, right-click (or Control-click) the app, choose Open,
  then Open again. On macOS 15 or later: try to open it once, then go to
  System Settings > Privacy & Security and click "Open Anyway".

In game, press F1 for the manual.

Crash reports are saved on your computer. On the next start the game asks
whether to send one; nothing is sent unless you press Send.
