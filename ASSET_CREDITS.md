# Asset credits and licenses

Assets added for Ironbound are original work made with the scripts in `tools/`, so they
are released under the project's MIT license (see `LICENSE`). Rebuild them with the
commands below to change them. No assets from Beyond All Reason or other non-commercial
sources are used.

| Assets | Made by | How to rebuild |
| --- | --- | --- |
| `assets/models/ironbound/` (desert props, deposits, units, buildings) | modelled procedurally in Blender (bpy 5.0) by `tools/blender/build_assets.py` | see `tools/blender/README.md` |
| `assets/textures/clouds_tile.png` | spectral noise generated by `tools/textures/make_cloud_texture.py` | `python3 tools/textures/make_cloud_texture.py` |
| `assets/audio/ambience/` (wind, rain, engine hum, city noise, trade horn) | synthesized from noise and sine waves by `tools/audio/make_soundscape.py` | `python3 tools/audio/make_soundscape.py` (needs numpy and ffmpeg) |
| `assets/audio/war/` (cannon, rifle and rocket fire, shell impacts, explosions, tank engine, rotor and drone loops) | synthesized from noise and sine waves by `tools/audio/make_war_sounds.py` | `python3 tools/audio/make_war_sounds.py` (needs numpy and ffmpeg) |
| `assets/audio/voices/` speech (infantry, vehicle crews, officers, pilots, builders, traders, advisor) | text-to-speech with the Kokoro-82M voice model (weights Apache 2.0, by hexgrad) run locally through kokoro-onnx (MIT), then radio-filtered with numpy by `tools/audio/make_voices.py`; lines in `tools/audio/voice_lines.json` | `python3 tools/audio/make_voices.py --kokoro-dir DIR` (see the script header) |
| `assets/audio/voices/` machine sounds (drone, auto_vehicle, structure) | synthesized from noise and sine waves by `tools/audio/make_voices.py` | `python3 tools/audio/make_voices.py --only drone,auto_vehicle,structure` |
| Terrain, water, cloud, cloud shadow and road shaders in `source/shaders/3d/` | written for this project | |

Third-party assets that were already in the project keep their own licenses:

- 3D Space Kit by Kenney.nl (CC0), `assets/models/kenney-spacekit/`
- Godot and Lampe Games logos, see `LOGO_LICENSES.md`
- The upstream unit and narrator voice lines made with ttsmaker.com (`assets/voice/`) were
  replaced by the voices above and removed.
